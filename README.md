🎮 Hangman Game (Python)

A simple and fun Hangman Game built using Python.
This project uses basic programming concepts like loops, conditionals, functions, and OOP (Object-Oriented Programming).

🚀 Features
🧠 Random word selection
💡 Hint system for each word
❤️ Lives system (6 chances)
🔁 Replay option
✅ Input validation
📊 Displays guessed letters
🛠️ Technologies Used
Python 3
Built-in random module
📂 Project Structure
hangman.py   # Main game file
README.md    # Project documentation
▶️ How to Run
Install Python (if not installed)
Download or clone this repository
Run the file:
python hangman.py
🎯 How to Play
You will be given a hint
Guess the word one letter at a time
You have 6 lives
Each wrong guess reduces a life
Guess the full word before lives run out!
